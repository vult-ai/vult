# Vult 0.5.2

Vult 0.5.2 makes coming back to Vult calmer and puts recovery codes in the
owner's hands.

- **A session that ends says so.** When a session ends, Vult says "Your session
  ended. For your security, Vult asks you to confirm it's you." with one
  Continue button, instead of saying you are signed out. After you sign in,
  Vult returns you to the page you were on.
- **Passkey sign-in looks like setup.** Sign-in opens on the same passkey dial
  as setup, with a help row for an authenticator app or a recovery code where
  you have one, and what to do if your passkey is gone.
- **Recovery codes go to the owner.** Setting up sign-in, an operator's reset
  and recovery with a code no longer hand codes to whoever ran them. Right
  after you sign in with the new method, Vult shows you a new set once and
  retires every earlier code, including any an operator was given before.
- **Clearer sign-in pages.** One notice style, a short "Opening Vult" step, and
  a recovery codes page that explains the codes and asks you to save them,
  with an optional backup authenticator.

## Upgrade

Run `vult update`, or the command you installed with:

```sh
curl -fsSL https://vult.sh | sh
```

Your Books, entries, sources, connections, keys and passkeys stay as they are.
0.5.2 adds one database migration, `0006_owner_recovery_codes.sql`, for the
sign-in data only. Recovery codes you saved earlier keep working until you
next set up or recover sign-in; then Vult shows you a new set.
