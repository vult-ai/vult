# Vult 0.5.0

Vult 0.5.0 lets you finish a Book in your browser, from its first entry to a
closed period, on your own computer or on a server.

- **Create Books in the browser.** Open **Books** and select **Create Book**.
  Choose Personal or Business, a name, the currency and the timezone. A
  Book's currency is fixed once it exists, so a server's first Book can be
  replaced by one in the currency you need before any entries are recorded.
- **Close a period.** In a Book's **Settings**, under **Accounting**, choose
  the first and last day and select **Close period**. Nothing dated inside a
  closed period can be posted or changed afterwards, by you or any agent.
  Closing is permanent; corrections go in a later, open period.
- **Sign out.** The profile menu now has **Sign out**, which ends the
  browser's session.
- **Exchange rates for agents.** The new `get_exchange_rate` tool returns a
  historical reference rate for one currency pair and date, from Frankfurter's
  blended reference rates. It uses the latest real observation on or before
  the date, at most seven days earlier, and says which day it came from. Only
  the pair and the date leave your computer. Agents still prefer the actual
  amount on a statement or receipt.
- **Closed periods for agents.** The new `list_closed_periods` tool shows
  which dates are closed, so an agent knows where corrections must go.
- **Agents that propose.** A new access level sits between read and record:
  a proposing agent reads the Book and prepares entries, and nothing reaches
  the Book until you approve it in Approvals. Choose it when you connect an
  agent, or change any agent's level later.
- **See every agent at a glance.** Settings → Connections lists each
  connected agent, whether it is active and its access level. Open one to
  change its level in each Book it reaches. Disconnected agents stay listed underneath.
- **Activity tabs count correctly.** Income and Expenses show and count the
  right entries in every Book, including Books kept only from card statements.
- **Original amounts beside recorded ones.** When a statement shows a charge
  in another currency, Activity shows it under the amount in the Book's
  currency, and entry details name the charged and billed amounts plainly.
- **A Book's type and timezone are set once.** Like its currency, they are
  fixed once chosen, so every report and closed period uses one calendar.
- **Clear tool names for agents.** Every MCP tool has a title, so agents'
  apps show "Post journal entry" rather than `post_journal`.
- **Recovers after an update.** A page left open across an update reloads
  itself instead of going blank.

## Upgrade

0.5.0 adds one database migration, for the propose access level; it changes no
existing records. Upgrading from 0.4.0 keeps your Books, entries, sources,
connections and keys, and backups made with 0.4.0 restore into 0.5.0. Back up
before upgrading:

```sh
vult backup --output books.age
```
