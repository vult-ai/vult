# Interface standards

Each document sets one part of the interface: a principle, the rules that
follow from it, and the check that keeps it true. Values live once, in the
tokens each document names, and the design checks (`npm run design:check` in
`web`) fail when code drifts from them.

| Standard | Covers |
| -- | -- |
| [App shell](shell.md) | The rail, the page bar, the canvas and phone navigation |
| [Toolbars](toolbars.md) | The band above a records table or list |
| [Search](search.md) | The ⌘K finder, and the search a page is filtered by |
| [Tables](tables.md) | Records tables |
| [Side panels](side-panels.md) | Details and summary panels beside a collection |
| [Menus](menus.md) | Action menus and option lists |
| [Dialogs](dialogs.md) | Modal dialogs and the document viewer |
| [Buttons](buttons.md) | Button colours, sizes and labels |
| [Forms](forms.md) | Fields, their labels, hints and errors |
| [Tabs and view filters](tabs.md) | Tab strips and the filters above a collection |
| [Feedback](feedback.md) | Loading, empty and failure states, notices and confirmations |
| [Visual tokens](tokens.md) | Corner radii, colours and icons |
| [Typography](typography.md) | Typefaces, type roles and numbers |
| [Avatars](avatars.md) | Account, institution and counterparty marks |
| [Dashboard](dashboard.md) | The Dashboard |
| [Settings](settings.md) | Settings and other supporting pages (draft) |
